# CatTalk

اپ فارسی React Native / Expo برای ثبت ارتباط با گربه، ساخت فرضیه از موقعیت و آموزش نشانه‌های ساده با صدای صاحب.

بخش مستقل **ترجمهٔ زندهٔ متن فارسی ↔ ژاپنی** نیز اضافه شده است: ترجمه هنگام تایپ، نمایش تدریجی پاسخ، تغییر جهت، لحن و کیفیت قابل انتخاب. کلید API فعلاً خالی است؛ محل تنظیم آن در `.env` آماده است. [راهنمای فعال‌سازی، مدل‌ها، پرامپت و منابع پژوهش](docs/TRANSLATION.md).

برای اجرای سرور ترجمه و پیش‌نمایش وب ساخته‌شده:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-Translation.ps1
# سپس http://localhost:8787 را باز کنید.
```

کلید را بعداً در `OPENAI_API_KEY` فایل `.env` قرار دهید و سرور را دوباره اجرا کنید. بدون کلید ابری، برای ترجمهٔ واقعی باید یکی از موتورهای محلی را نصب و اجرا کنید. متن ترجمه برای پردازش به سرویس انتخاب‌شده ارسال می‌شود؛ قابلیت‌های صوتی گربه همچنان محلی‌اند.

## وضعیت علمی

این نسخه **مدل آموزش‌دیدهٔ تحلیل میو ندارد**. صدای واقعی ضبط و ذخیره می‌شود، اما تفسیر از مکان، زبان بدن و نوع صدای گزارش‌شده توسط کاربر ساخته می‌شود. خروجی‌ها فرضیه‌اند؛ هیچ درصد اطمینان، تشخیص پزشکی یا ترجمهٔ جمله‌به‌جمله ارائه نمی‌شود. شخصی‌سازی یک قاعدهٔ محدود بر بازخوردهای همان گربه است، نه یادگیری مدل صوتی.

## اجرا

در همین رایانه، لانچر زیر از Node جدید همراه محیط استفاده می‌کند (Node پیش‌فرض سیستم قدیمی است):

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-CatTalk.ps1
# برای نمایش QR و اجرای موبایل:
powershell -ExecutionPolicy Bypass -File .\Start-CatTalk.ps1 -Mobile
```

Node.js 22.13 یا جدیدتر توصیه می‌شود. نسخه‌های سازگار با Expo SDK 54 در package-lock.json قفل شده‌اند.

```powershell
npm ci
npm start
```

برای اجرای موبایل از کلاینت سازگار با Expo SDK 54 یا development build استفاده کنید. موبایل و رایانه باید به یک شبکه دسترسی داشته باشند. نسخهٔ Expo Go باید با SDK پروژه سازگار باشد.

```powershell
npm run web
npm run typecheck
npm test
npm run export:web
```

پیش‌نمایش مرورگر قابلیت ضبط دارد؛ دسترسی میکروفون به `localhost` یا HTTPS نیاز دارد. برای دستگاه فیزیکی، نشانی HTTP رایانه در مرورگر مناسب ضبط نیست؛ از اجرای native یا HTTPS استفاده کنید.

## خروجی اندروید

پروفایل APK در eas.json آماده است. این مرحله به حساب Expo و سرویس ساخت یا Android SDK محلی نیاز دارد:

```powershell
npx eas-cli build --platform android --profile preview
```

این مخزن به‌خودی‌خود APK امضاشده یا نسخهٔ منتشرشده در فروشگاه نیست. ساخت iOS به تنظیمات امضا و حساب مربوط نیاز دارد.

## امکانات

- چند پروفایل گربه و جداسازی تاریخچه و پیام‌های هر گربه.
- ضبط صوت تا ۲۰ ثانیه، پخش مجدد و ثبت مشاهدات بدون الزام ضبط.
- تفسیر زمینه‌محور همراه شواهد، پیشنهاد اقدام و حالت «اطلاعات کافی نیست».
- بازخورد کاربر و ثبت نتیجهٔ قابل‌مشاهده؛ اصلاح بازخورد و حذف مشاهده.
- ضبط سه نشانهٔ انسانی تا ۸ ثانیه، پخش و ثبت واکنش مرتبط.
- ذخیرهٔ محلی و حذف پروفایل همراه با داده‌های وابسته.
- رابط فارسی، منابع علمی و توضیح محدودیت‌ها داخل اپ.

## ساختار

- `App.tsx`: صفحه‌ها و جریان کار
- `src/domain.ts`: قواعد مستقل تفسیر و انواع داده
- `src/Recorder.tsx`: مجوز، ضبط، محدودیت زمان و پخش
- `src/audioFiles.ts`: فایل‌های دائمی native
- `src/audioFiles.web.ts`: تبدیل ضبط وب به data URI برای ماندگاری پس از reload
- `src/storage.ts`: ذخیرهٔ محلی AsyncStorage
- `tests/domain.test.ts`: آزمون عدم قطعیت، جداسازی گربه‌ها و تعارض شواهد

صداهای وب در فضای ذخیره‌سازی مرورگر نگه داشته می‌شوند و محدودیت حجم دارند. خطای ظرفیت به کاربر نمایش داده می‌شود. حذف دادهٔ مرورگر یا اپ داده‌ها را از دسترس خارج می‌کند؛ همگام‌سازی و پشتیبان ابری پیاده نشده است. در native فایل‌ها به پوشهٔ document اپ کپی می‌شوند.

## بررسی‌های انجام‌شده

- TypeScript بدون خطا.
- ۸۴ آزمون منطق تفسیر، ترجمهٔ جریانی، لغو درخواست، اعتبارسنجی، واژه‌نامه، زمینهٔ مخاطب، بازبینی ویس، OCR و صف/خروجی جلسه موفق.
- آزمون رابط ترجمه با پاسخ‌های آزمایشی: وضعیت بدون کلید، هر دو جهت زبان، تایپ ژاپنی IME در وب، بازیابی خطا و نمایش ۳۲۰ پیکسلی موفق. کیفیت ترجمهٔ مدل زنده هنوز آزموده نشده است.
- خروجی production وب، Android و iOS موفق. خروجی‌های native بستهٔ JavaScript/Hermes هستند، نه فایل نصب امضاشده.
- آزمون مرورگر در اندازهٔ ۳۹۰×۸۴۴: ساخت پروفایل، ضبط با میکروفون مصنوعی Chromium، پخش، ماندگاری صدا و بازخورد پس از reload، ضبط نشانهٔ صاحب، شمارش پاسخ، جداسازی دو گربه و حذف وابسته موفق؛ خطای runtime ثبت نشد.
- اجرای روی گوشی فیزیکی و ساخت APK/IPA در این محیط انجام نشده است؛ Android SDK نصب نیست.

آزمون مرورگر در `tests/smoke.cjs` قرار دارد. به Playwright و Chrome نیاز دارد (در این محیط از runtime همراه ابزار استفاده می‌کند). پس از ساخت وب، `dist` را با سرور محلی روی پورت ۸۰۸۲ سرو کنید و `npm run test:ui` را اجرا کنید. نشانی را می‌توان با `CATTALK_URL` و مسیر Chrome را با `CHROME_PATH` تعیین کرد. این آزمون دادهٔ مصنوعی را فقط در context مجزای مرورگر ایجاد می‌کند.

## مسیر مدل پژوهشی

پیش از افزودن مدل صوتی باید دادهٔ دارای مجوز و برچسب معتبر جمع‌آوری شود. جداسازی train/test باید بر اساس گربه، خانه و جلسه باشد. مقایسه با baseline فقط‌زمینه، ارزیابی روی گوشی واقعی، کالیبراسیون و امکان خودداری از پاسخ لازم است. مدل صوتی آینده باید به‌عنوان سرویس جدا جایگزین یا مکمل `interpret` شود؛ متن انسانی نباید به معنای اثبات‌شدهٔ صدا تبدیل شود.

منابع پایه: [مرور ارتباط صوتی](https://pubmed.ncbi.nlm.nih.gov/32017479/)، [طبقه‌بندی موقعیت](https://pmc.ncbi.nlm.nih.gov/articles/PMC6719916/)، [CatMeows](https://zenodo.org/records/4008297)، [پلک‌زدن آهسته](https://www.nature.com/articles/s41598-020-73426-0)، [گفتار صاحب](https://pubmed.ncbi.nlm.nih.gov/36280656/)، [ارتباط چندحسی](https://pmc.ncbi.nlm.nih.gov/articles/PMC10177025/)، [یادگیری واژه و تصویر](https://www.nature.com/articles/s41598-024-74006-2).


## سرویس‌های جایگزین ترجمه

در صفحهٔ ترجمه بین Google Gemini، Groq، OpenRouter Free و ChatGPT / OpenAI سوییچ کنید. سه گزینهٔ اول سهمیه/مسیر رایگان محدود دارند؛ کلید حساب همچنان لازم است. جای `GEMINI_API_KEY`، `GROQ_API_KEY` و `OPENROUTER_API_KEY` در `.env` آماده شده است. فقط کلید سرویس دلخواه را تنظیم و سرور را دوباره اجرا کنید. [راهنما و منابع رسمی](docs/TRANSLATION.md).

گزینهٔ **ChatGPT / OpenAI** با `OPENAI_API_KEY` به API رسمی متصل است و داخل برنامه راهنمای ساخت کلید دارد. API هزینهٔ جدا از اشتراک ChatGPT دارد؛ ایران در فهرست رسمی کشورهای پشتیبانی‌شده نیست. [راهنمای راه‌اندازی و محدودهٔ قابلیت‌ها](docs/OPENAI_SETUP.md).

## ترجمهٔ صوتی فارسی ↔ ژاپنی

در تب ترجمه، «ترجمهٔ صوتی» را انتخاب کنید: ارسال فایل ویس یا مکالمه با میکروفون. خروجی متن و پخش جمله‌های ترجمه‌شده ارائه می‌شود. کل صدای هر نوبت تا ۳ ثانیه سکوت جمع می‌شود و سپس یک‌جا ترجمه می‌شود. حالت پیش‌فرض متعادل است؛ پخش پس از تکمیل کل ترجمه شروع می‌شود و هنگام ترجمه/پخش، میکروفون مکث می‌کند.

STT با Faster Whisper محلیِ بدون کلید یا Groq/Gemini و پخش با صدای دستگاه یا Gemini فراهم است. جای کلیدها و مدل‌های صوتی در `.env` آماده است. کلید واقعی هنوز تنظیم نشده؛ آزمون‌های سرویس با پاسخ آزمایشی انجام شده‌اند. [راهنمای کامل صوت و منابع](docs/VOICE.md).

## مدل‌های کاملاً رایگان محلی

TranslateGemma، Qwen و LibreTranslate خودمیزبان اضافه شده‌اند و داخل اپ با برچسب «کاملاً رایگان در اجرای محلی» از سرویس‌های دارای سهمیهٔ رایگان جدا هستند. ترجمهٔ متن به کلید API یا پرداخت هر درخواست نیاز ندارد؛ نصب موتور و مدل روی رایانهٔ خودتان لازم است. [راهنمای نصب و شرایط رایگان‌بودن](docs/LOCAL_TRANSLATION.md). لانچر: `Start-LocalTranslation.ps1`. مدل واقعی هنوز در این محیط نصب نشده؛ اتصال‌ها با پاسخ آزمایشی بررسی شده‌اند.

## کاهش مصرف درخواست روی گوشی

تشخیص مکث، ضبط، صف پخش و لغو درخواست روی گوشی اجرا می‌شوند. پاسخ ترجمهٔ موفق برای متن و تنظیمات کاملاً یکسان تا ۲ دقیقه در حافظهٔ همان صفحه بازاستفاده می‌شود؛ بدون نوشتن در فایل و با امکان خاموش‌کردن برای درخواست تازه. متن/زمینه خلاصه یا بازنویسی نمی‌شوند. [تقسیم کار گوشی و مدل و جزئیات صرفه‌جویی](docs/ON_DEVICE.md).

## مترجم چت پیام‌رسان‌ها

در تب ترجمه، «مترجم چت» را انتخاب کنید. پیام دریافتی و پاسخ فارسی/ژاپنی جدا ترجمه می‌شوند. حساب شخصی با کپی/اشتراک پیام و انتقال پیش‌نویس کار می‌کند. دریافت متن از Share در نسخهٔ native جدید آماده شده و به build نصب‌شدنی نیاز دارد.

اتصال رسمی تلگرام Bot/Business، WhatsApp Business و Instagram حرفه‌ای نیز با webhook تأییدشده، صندوق موقت و ارسال پس از پیش‌نمایش پیاده شده است؛ کلیدها و مجوز حساب هنوز تنظیم نشده‌اند. [راهنمای اتصال و محدودیت‌ها](docs/MESSAGING.md).

## امکانات جدید کیفیت ترجمه

واژه‌نامهٔ شخصی، زمینهٔ اختیاری و محدود برای هر مخاطب، پروفایل لحن، بازبینی و اصلاح متن ویس بدون تشخیص گفتار دوباره، هشدار محلی اعداد/لینک/جای‌نگهدار، دو پیشنهاد ترجمه فقط با درخواست کاربر و استخراج متن اسکرین‌شات قابل‌ویرایش اضافه شده‌اند. حالت تصویر به `GEMINI_API_KEY` نیاز دارد؛ محل مدل `GEMINI_OCR_MODEL` در `.env` آماده است.

[راهنمای استفاده، مصرف و محدودیت‌های هر موتور](docs/TRANSLATION_QUALITY.md). آزمون مرورگر امکانات جدید: `node tests/enhancements-ui.cjs`؛ پاسخ مدل و OCR در آزمون، fixture هستند. این آزمون ذخیره و بازیابی واژه‌نامه، جداسازی زمینهٔ مخاطبان، لحن، بازبینی ویس، درخواست اختیاری پیشنهادها و انتقال متن تصویر به ترجمه را بررسی می‌کند. مجموعهٔ اولیهٔ بازبینی انسانی در `tests/fixtures/translation-quality.json` آماده است؛ نتیجهٔ کیفیت مدل زنده محسوب نمی‌شود.

## همراه سفر و جلسه

براساس بررسی منابع رسمی Google Translate، Microsoft Translator، DeepL Voice، KUDO و راهنمای تفسیر کنفرانس سازمان ملل، این امکانات اضافه شدند:

- عبارت‌نامهٔ همراه اپ با ۲۰ عبارت عمومی، جستجو، نمایش بزرگ و ذخیرهٔ اختیاری تا ۱۰۰ ترجمه.
- نمای رو‌به‌رو برای گفتگوی فارسی و ژاپنی و انتخاب گویندهٔ هر نوبت.
- انتخاب Whisper سریع/کامل، راهنمای اختیاری نام‌ها از واژه‌نامه و کنترل سرعت پخش.
- حالت جلسه با ضبط نوبت بعدی هنگام پردازش قبلی، صف محدود سه نوبتی، زیرنویس پایدار و ثبت وضعیت خطا/لغو.
- بازبینی متن ویس و تأیید ترجمه پیش از انتشار، متن جلسه در RAM و خروجی JSON/SRT با انتخاب کاربر.
- شدت ورودی میکروفون و زمان‌بندی جداگانهٔ صف، تشخیص و ترجمه.

[راهنما، منابع رسمی و حدود قابلیت‌های سفر/کنفرانس](docs/TRAVEL_CONFERENCE.md). حالت جلسه و گفتگو، مکث سه‌ثانیه‌ای را حفظ می‌کنند؛ در مرز نوبت‌ها وقفهٔ کوتاه ضبط وجود دارد. ترجمهٔ ماشینی بی‌نقص، ضبط پیوستهٔ بدون شکاف، اتصال مستقیم جلسات آنلاین یا تأیید استفادهٔ دیپلماتیک ادعا نمی‌شود. آزمون مستقل: `node tests/sessions-ui.cjs`، با صدا و پاسخ مدل آزمایشی.

## تشخیص گفتار کاملاً رایگان محلی

Faster Whisper محلی به فایل ویس، میکروفون و جلسه اضافه شده است. کتابخانه و مدل چندزبانهٔ small در این محیط نصب شده‌اند و اجرای واقعی آفلاین و مسیر واقعی سرور بررسی شدند. در انتخاب موتور تشخیص گفتار، «Faster Whisper محلی · رایگان» را برگزینید. برای ترجمهٔ متن، موتور محلی را جدا انتخاب و نصب کنید.

راه‌انداز: `Start-LocalVoice.ps1`. [راهنمای نصب، تنظیم مدل، حریم داده و حدود آزمون](docs/LOCAL_VOICE.md). هشت آزمون جدید Node، چهار آزمون Python و آزمون رابط محلی موفق هستند؛ کیفیت گفتار طبیعی با نمونهٔ بومی هنوز ارزیابی نشده است.
