# CatTalk

اپ فارسی React Native / Expo برای ثبت ارتباط با گربه، ساخت فرضیه از موقعیت و آموزش نشانه‌های ساده با صدای صاحب.

بخش مستقل **ترجمهٔ زندهٔ متن فارسی ↔ ژاپنی** نیز اضافه شده است: ترجمه هنگام تایپ، نمایش تدریجی پاسخ، تغییر جهت، لحن و کیفیت قابل انتخاب. کلید API فعلاً خالی است؛ محل تنظیم آن در `.env` آماده است. [راهنمای فعال‌سازی، مدل‌ها، پرامپت و منابع پژوهش](docs/TRANSLATION.md).

برای اجرای سرور ترجمه و پیش‌نمایش وب ساخته‌شده:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-Translation.ps1
# سپس http://localhost:8787 را باز کنید.
```

کلید را بعداً در `OPENAI_API_KEY` فایل `.env` قرار دهید و سرور را دوباره اجرا کنید. بدون کلید، رابط قابل استفاده و بررسی است ولی ترجمهٔ واقعی فعال نیست. متن ترجمه برای پردازش به سرویس انتخاب‌شده ارسال می‌شود؛ قابلیت‌های صوتی گربه همچنان محلی‌اند.

## وضعیت علمی

این نسخه **مدل آموزش‌دیدهٔ تحلیل میو ندارد**. صدای واقعی ضبط و ذخیره می‌شود، اما تفسیر از مکان، زبان بدن و نوع صدای گزارش‌شده توسط کاربر ساخته می‌شود. خروجی‌ها فرضیه‌اند؛ هیچ درصد اطمینان، تشخیص پزشکی یا ترجمهٔ جمله‌به‌جمله ارائه نمی‌شود. شخصی‌سازی یک قاعدهٔ محدود بر بازخوردهای همان گربه است، نه یادگیری مدل صوتی.

## اجرا

در همین رایانه، لانچر زیر از Node جدید همراه محیط استفاده می‌کند (Node پیش‌فرض سیستم قدیمی است):

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-CatTalk.ps1
# برای نمایش QR و اجرای موبایل:
powershell -ExecutionPolicy Bypass -File .\Start-CatTalk.ps1 -Mobile
```

Node.js 22.13 یا جدیدتر توصیه می‌شود. نسخه‌های سازگار با Expo SDK 54 در package-lock.json قفل شده‌اند.

```powershell
npm ci
npm start
```

برای اجرای موبایل از کلاینت سازگار با Expo SDK 54 یا development build استفاده کنید. موبایل و رایانه باید به یک شبکه دسترسی داشته باشند. نسخهٔ Expo Go باید با SDK پروژه سازگار باشد.

```powershell
npm run web
npm run typecheck
npm test
npm run export:web
```

پیش‌نمایش مرورگر قابلیت ضبط دارد؛ دسترسی میکروفون به `localhost` یا HTTPS نیاز دارد. برای دستگاه فیزیکی، نشانی HTTP رایانه در مرورگر مناسب ضبط نیست؛ از اجرای native یا HTTPS استفاده کنید.

## خروجی اندروید

پروفایل APK در eas.json آماده است. این مرحله به حساب Expo و سرویس ساخت یا Android SDK محلی نیاز دارد:

```powershell
npx eas-cli build --platform android --profile preview
```

این مخزن به‌خودی‌خود APK امضاشده یا نسخهٔ منتشرشده در فروشگاه نیست. ساخت iOS به تنظیمات امضا و حساب مربوط نیاز دارد.

## امکانات

- چند پروفایل گربه و جداسازی تاریخچه و پیام‌های هر گربه.
- ضبط صوت تا ۲۰ ثانیه، پخش مجدد و ثبت مشاهدات بدون الزام ضبط.
- تفسیر زمینه‌محور همراه شواهد، پیشنهاد اقدام و حالت «اطلاعات کافی نیست».
- بازخورد کاربر و ثبت نتیجهٔ قابل‌مشاهده؛ اصلاح بازخورد و حذف مشاهده.
- ضبط سه نشانهٔ انسانی تا ۸ ثانیه، پخش و ثبت واکنش مرتبط.
- ذخیرهٔ محلی و حذف پروفایل همراه با داده‌های وابسته.
- رابط فارسی، منابع علمی و توضیح محدودیت‌ها داخل اپ.

## ساختار

- `App.tsx`: صفحه‌ها و جریان کار
- `src/domain.ts`: قواعد مستقل تفسیر و انواع داده
- `src/Recorder.tsx`: مجوز، ضبط، محدودیت زمان و پخش
- `src/audioFiles.ts`: فایل‌های دائمی native
- `src/audioFiles.web.ts`: تبدیل ضبط وب به data URI برای ماندگاری پس از reload
- `src/storage.ts`: ذخیرهٔ محلی AsyncStorage
- `tests/domain.test.ts`: آزمون عدم قطعیت، جداسازی گربه‌ها و تعارض شواهد

صداهای وب در فضای ذخیره‌سازی مرورگر نگه داشته می‌شوند و محدودیت حجم دارند. خطای ظرفیت به کاربر نمایش داده می‌شود. حذف دادهٔ مرورگر یا اپ داده‌ها را از دسترس خارج می‌کند؛ همگام‌سازی و پشتیبان ابری پیاده نشده است. در native فایل‌ها به پوشهٔ document اپ کپی می‌شوند.

## بررسی‌های انجام‌شده

- TypeScript بدون خطا.
- ۲۷ آزمون منطق تفسیر، ترجمهٔ جریانی، لغو درخواست، اعتبارسنجی و خطاها موفق.
- آزمون رابط ترجمه با پاسخ‌های آزمایشی: وضعیت بدون کلید، هر دو جهت زبان، تایپ ژاپنی IME در وب، بازیابی خطا و نمایش ۳۲۰ پیکسلی موفق. کیفیت ترجمهٔ مدل زنده هنوز آزموده نشده است.
- خروجی production وب، Android و iOS موفق. خروجی‌های native بستهٔ JavaScript/Hermes هستند، نه فایل نصب امضاشده.
- آزمون مرورگر در اندازهٔ ۳۹۰×۸۴۴: ساخت پروفایل، ضبط با میکروفون مصنوعی Chromium، پخش، ماندگاری صدا و بازخورد پس از reload، ضبط نشانهٔ صاحب، شمارش پاسخ، جداسازی دو گربه و حذف وابسته موفق؛ خطای runtime ثبت نشد.
- اجرای روی گوشی فیزیکی و ساخت APK/IPA در این محیط انجام نشده است؛ Android SDK نصب نیست.

آزمون مرورگر در `tests/smoke.cjs` قرار دارد. به Playwright و Chrome نیاز دارد (در این محیط از runtime همراه ابزار استفاده می‌کند). پس از ساخت وب، `dist` را با سرور محلی روی پورت ۸۰۸۲ سرو کنید و `npm run test:ui` را اجرا کنید. نشانی را می‌توان با `CATTALK_URL` و مسیر Chrome را با `CHROME_PATH` تعیین کرد. این آزمون دادهٔ مصنوعی را فقط در context مجزای مرورگر ایجاد می‌کند.

## مسیر مدل پژوهشی

پیش از افزودن مدل صوتی باید دادهٔ دارای مجوز و برچسب معتبر جمع‌آوری شود. جداسازی train/test باید بر اساس گربه، خانه و جلسه باشد. مقایسه با baseline فقط‌زمینه، ارزیابی روی گوشی واقعی، کالیبراسیون و امکان خودداری از پاسخ لازم است. مدل صوتی آینده باید به‌عنوان سرویس جدا جایگزین یا مکمل `interpret` شود؛ متن انسانی نباید به معنای اثبات‌شدهٔ صدا تبدیل شود.

## سرویس‌های جایگزین ترجمه

در صفحهٔ ترجمه بین Google Gemini، Groq، OpenRouter Free و OpenAI سوییچ کنید. سه گزینهٔ اول سهمیه/مسیر رایگان محدود دارند؛ کلید حساب همچنان لازم است. جای `GEMINI_API_KEY`، `GROQ_API_KEY` و `OPENROUTER_API_KEY` در `.env` آماده شده است. فقط کلید سرویس دلخواه را تنظیم و سرور را دوباره اجرا کنید.
