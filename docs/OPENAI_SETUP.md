# اتصال ChatGPT / OpenAI

گزینهٔ «ChatGPT / OpenAI» در انتخاب هوش مصنوعی به مدل‌های GPT از طریق API رسمی OpenAI متصل است. اتصال Responses API جریانی از قبل پیاده شده بود؛ در این تغییر نام قابل تشخیص، راهنمای داخل برنامه و پیوندهای ساخت کلید، تعرفه و کشورهای پشتیبانی‌شده اضافه شدند.

## پیش از ساخت حساب

- مصرف API براساس تعرفهٔ API است و اعتبار آن جدا از اشتراک ChatGPT حساب می‌شود. داشتن Plus یا Pro به‌تنهایی اعتبار موردنیاز این اتصال را فراهم نمی‌کند.
- ایران در فهرست رسمی کشورهای پشتیبانی‌شدهٔ OpenAI API نیست. ساخت کلید مشکل دسترسی از منطقهٔ پشتیبانی‌نشده را برطرف نمی‌کند. ژاپن در این فهرست است.
- نام مدل و تنظیم بودن کلید، دسترسی واقعی حساب یا داشتن اعتبار را تضمین نمی‌کند؛ درخواست واقعی این موارد را مشخص می‌کند. در این تغییر، آزمون API پولی زنده انجام نشده است.

## ساخت کلید و راه‌اندازی

1. از [داشبورد کلیدهای OpenAI](https://platform.openai.com/api-keys) کلید API بسازید؛ دسترسی و صورتحساب پروژه را در حساب API بررسی کنید.
2. کلید را فقط در `.env` سرور و مقابل `OPENAI_API_KEY` قرار دهید. آن را در چت، مخزن، اپ یا متغیرهای `EXPO_PUBLIC_*` نگذارید.
3. سرور را با `Start-Translation.ps1` دوباره اجرا کنید.
4. در تب ترجمه، «ChatGPT / OpenAI» را انتخاب و «بررسی دوباره» را بزنید.

تنظیم «توکن اتصال به سرور» داخل اپ مربوط به `TRANSLATION_ACCESS_TOKEN` است؛ کلید OpenAI نباید در آن وارد شود. سرور هنگام ارسال درخواست از کلید استفاده می‌کند و مقدار کلید را در وضعیت اتصال یا پاسخ کلاینت برنمی‌گرداند.

## قابلیت‌ها

این انتخاب برای ترجمهٔ متن، پیام‌های دریافتی و پاسخ چت، متن استخراج‌شده از ویس و نوبت‌های جلسه است. واژه‌نامه، لحن، زمینه، هشدارهای محلی و پیشنهاد جایگزین در همین مسیر کار می‌کنند. هر درخواست و پیشنهاد جدا می‌تواند هزینه داشته باشد.

در مسیر صوتی، تشخیص گفتار و پخش همچنان موتور مستقل انتخابی خودشان را دارند؛ برای نمونه Faster Whisper محلی → ترجمهٔ OpenAI → صدای دستگاه. انتخاب OpenAI برای ترجمه، به‌صورت خودکار تشخیص گفتار، تولید صدا یا OCR تصویر را به OpenAI منتقل نمی‌کند. OCR این نسخه همچنان Gemini است.

مدل‌های متن از `OPENAI_TRANSLATION_MODEL`، `OPENAI_TRANSLATION_FAST_MODEL` و `OPENAI_TRANSLATION_QUALITY_MODEL` خوانده می‌شوند. در این تغییر مدل‌ها یا پرامپت جابه‌جا نشده‌اند. آزمون اختصاصی کیفیت فارسی ↔ ژاپنی با حساب زنده هنوز انجام نشده است.
