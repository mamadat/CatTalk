# ترجمهٔ زندهٔ فارسی ↔ ژاپنی

این بخش مستقل از قابلیت‌های گربه است و بدون ساخت پروفایل کار می‌کند. زبان پیاده‌سازی **TypeScript** است: React Native/Expo برای موبایل و Node.js برای سرور. این انتخاب با پروژهٔ موجود سازگار است و امکان اشتراک قرارداد درخواست‌ها و مدیریت جریان پاسخ و لغو درخواست را می‌دهد؛ زبان برنامه‌نویسی به‌تنهایی کیفیت ترجمه را تعیین نمی‌کند.

## فعال‌سازی بعداً، با کلید

فایل `.env` در ریشهٔ پروژه آماده است و `OPENAI_API_KEY` فعلاً خالی است. کلید را فقط در همین فایل سرور قرار دهید؛ داخل کد موبایل، متغیرهای `EXPO_PUBLIC_*` یا چت قرار ندهید. `.env` در Git نادیده گرفته می‌شود؛ `.env.example` نمونهٔ بدون کلید است.

```powershell
# پس از تنظیم OPENAI_API_KEY در .env:
powershell -ExecutionPolicy Bypass -File .\Start-Translation.ps1
```

پیش‌نمایش وب ساخته‌شده و API هر دو روی `http://localhost:8787` در دسترس‌اند. بعد از تغییر کلید یا مدل، سرور را دوباره اجرا کنید. روی رایانه‌ای دیگر با Node 22.13+، `npm ci`، سپس `npm run export:web` و `npm run api` را اجرا کنید. بدون کلید، رابط در دسترس است اما پیام «سرویس هنوز فعال نشده» نشان می‌دهد و ترجمهٔ ساختگی تولید نمی‌کند.

در موبایل، «تنظیم اتصال» را باز کنید و نشانی سرور را وارد کنید. localhost گوشی به رایانه اشاره نمی‌کند. برای سرور قابل دسترسی از شبکه، `TRANSLATION_HOST`، `TRANSLATION_ACCESS_TOKEN` و `TRANSLATION_ALLOWED_ORIGINS` را تنظیم کنید. توکن اتصال با کلید OpenAI متفاوت است و در اپ فقط تا پایان جلسه نگه داشته می‌شود. برای استفادهٔ اینترنتی HTTPS لازم است؛ انتشار عمومی و مدیریت حساب‌های چندکاربره در این مرحله انجام نشده است. آدرس عمومی سرور را می‌توان پیش از ساخت در `EXPO_PUBLIC_TRANSLATION_URL` تنظیم کرد.

## رفتار زنده

- ۴۵۰ میلی‌ثانیه بعد از مکث تایپ، درخواست ارسال می‌شود و خروجی به‌صورت جریان متن ظاهر می‌شود؛ این زمان، تضمین زمان پاسخ مدل نیست.
- ویرایش بعدی، درخواست قبلی را لغو می‌کند؛ پاسخ دیررس نمی‌تواند متن جدید را بازنویسی کند.
- ورودی ژاپنی در وب هنگام composition/IME منتظر تکمیل تایپ می‌ماند. رفتار صفحه‌کلیدهای native باید روی گوشی واقعی ارزیابی شود.
- تغییر جهت، انتخاب لحن، زمینهٔ اختیاری، ترجمهٔ دستی، تلاش مجدد و کپی/اشتراک خروجی آماده‌اند.
- ورودی تا ۲۰۰۰ کاراکتر و زمینه تا ۵۰۰ کاراکتر؛ پاسخ ناقص یا قطع‌شده به‌عنوان ترجمهٔ کامل نمایش داده نمی‌شود.
- سرور دارای محدودیت درخواست، مهلت پاسخ، کنترل مبدا و توکن اختیاری است. متن در دفترچه، فایل یا لاگ سرور ذخیره نمی‌شود؛ درخواست به ارائه‌دهنده با `store:false` فرستاده می‌شود. این گزینه معادل تضمین عدم نگهداری داده در تمام سامانه‌های ارائه‌دهنده نیست.

## مدل و پرامپت

مدل‌ها در `.env` قابل تغییرند: حالت متعادل `gpt-6.1-sol`، دقت بیشتر `gpt-6-astra` و سریع‌تر `gpt-6-luna`. این انتخاب بر اساس مستندات فعلی و توازن قابلیت/سرعت است، نه نتیجهٔ بنچمارک اختصاصی فارسی–ژاپنی. دسترسی به مدل به حساب API بستگی دارد. حالت سریع reasoning برابر `none` و دو حالت دیگر `low` دارند؛ جایگزینی مدل باید با این تنظیم سازگار باشد.

پرامپت اصلی و نسخه‌بندی‌شده در [`server/prompt.ts`](../server/prompt.ts) است. دستورها انگلیسی‌اند و قواعد صریح هر دو زبان را دارند: حفظ نفی، احتمال، عدد و نام؛ انتقال طبیعی اصطلاحات و تعارف؛ انتخاب لحن ژاپنی بدون افزودن رابطهٔ اجتماعی فرضی؛ فارسی ایرانی با ی/ک و نیم‌فاصله؛ حفظ پیوند، کد و جای‌نگهدارها؛ عدم پاسخ‌دادن به دستورهای داخل متن؛ و خروجی صرفاً ترجمه. متن و زمینه به‌صورت دادهٔ JSON جدا از دستور اصلی ارسال می‌شوند. این جداسازی ریسک اجرای دستورهای داخل متن را کاهش می‌دهد ولی تضمین کامل رفتار مدل نیست.

## منابع و تصمیم‌های پژوهشی

بررسی در ۲۵ اکتبر ۲۰۲۶ انجام شد؛ ادعای بررسی همهٔ اپ‌ها یا همهٔ مقالات مطرح نیست.

- [NextAI Translator](https://github.com/nextai-translator/nextai-translator): README و فایل‌های `src/common/translate.ts` و `src/common/engines/openai.ts` بررسی شدند. الگوی stream، AbortSignal و جداسازی موتور ترجمه الهام‌بخش ساختار این بخش بود. کد آن پروژه کپی نشده است.
- [Immersive Translate](https://github.com/immersive-translate/immersive-translate): مستندات نمایش دوزبانه و حفظ زمینه بررسی شد؛ نه ممیزی کامل پیاده‌سازی داخلی.
- [Google Cloud Translation](https://docs.cloud.google.com/translate/docs/languages): پشتیبانی فارسی و ژاپنی، به‌عنوان گزینهٔ قابل مقایسه در ارزیابی بعدی.
- [LibreTranslate languages](https://github.com/LibreTranslate/Documentation/blob/main/src/content/docs/guides/supported_languages.md): مسیرهای ترجمه و امکان واسطه‌شدن انگلیسی؛ برای این نسخه گزینهٔ پیش‌فرض نشد.
- [OpenAI models](https://developers.openai.com/api/docs/models)، [راهنمای مدل‌ها](https://developers.openai.com/api/docs/guides/latest-model) و [Streaming Responses](https://developers.openai.com/api/docs/guides/streaming-responses): مبنای انتخاب مدل قابل تنظیم و پیاده‌سازی API سمت سرور.

## ارزیابی

`npm test` منطق لغو، debounce، جریان UTF-8، timeout، خطا، اعتبارسنجی و جداسازی متن از دستور را بررسی می‌کند. `node tests/translation-ui.cjs` بعد از ساخت وب و اجرای سرور بدون کلید، رابط را با پاسخ‌های صریحاً آزمایشی بررسی می‌کند. آزمون رابط کلید واقعی مصرف نمی‌کند. تست‌های mock کیفیت زبان یا مقاومت واقعی مدل در برابر تزریق دستور را اثبات نمی‌کنند.

پس از دریافت کلید، هر سه مدل را روی متن‌های یکسان با داور مسلط به هر دو زبان مقایسه کنید. معیارها: حفظ معنی و نفی، طبیعی‌بودن، لحن، نام/عدد، زمان اولین متن، زمان کامل و هزینه. نمونه‌های ضروری:

| ورودی | ویژگی مورد بررسی |
|---|---|
| احتمالاً فردا نمی‌توانم بیایم. | حفظ احتمال و نفی |
| لطفاً مبلغ ۱۲۵۰ ین را تا جمعه پرداخت کنید. | عدد، واحد، مهلت و ادب |
| دستت درد نکنه، خیلی کمکم کردی. | ترجمهٔ کاربرد اصطلاح، نه درد دست |
| 来週までに提出しなくてもいいです。 | «لازم نیست» با «نباید» اشتباه نشود |
| 先生はもうお帰りになりました。 | احترام بدون افزودن جنسیت |
| مقدار `{count}` را در https://example.com تغییر نده. | حفظ جای‌نگهدار و URL |

تا زمان اجرای این ارزیابی، هیچ ادعای «بهترین دقت» یا ترجمهٔ بدون خطا برای این جفت‌زبان وجود ندارد.
