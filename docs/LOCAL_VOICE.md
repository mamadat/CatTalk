# تشخیص گفتار محلی و رایگان

در ۲۸ اکتبر ۲۰۲۶، Faster Whisper به دریافت فایل ویس، میکروفون و حالت جلسهٔ CatTalk متصل شد. مدل چندزبانهٔ `small` و کتابخانه‌ها در همین محیط نصب و مسیر واقعی `/api/transcribe` نیز اجرا شد. این مدل تشخیص گفتار است؛ برای ترجمهٔ متن استخراج‌شده، موتور ترجمه جدا انتخاب می‌شود.

## استفاده در برنامه

1. تب «ترجمه» را باز کنید و موتور ترجمه را انتخاب کنید. برای ترجمهٔ متن بدون هزینهٔ API، یکی از موتورهای محلیِ نصب‌شده را برگزینید.
2. در «ترجمهٔ صوتی» یا «جلسه و زیرنویس»، گزینهٔ **Faster Whisper محلی · رایگان** را انتخاب کنید. وضعیت نصب و آماده‌بودن نمایش داده می‌شود.
3. زبان ورودی را فارسی یا ژاپنی انتخاب کنید. فایل ویس را بفرستید یا میکروفون را شروع کنید. مکث سه‌ثانیه‌ای و ترجمهٔ کل نوبت حفظ شده‌اند.
4. در ویس برای خروجی بدون کلید TTS، «صدای دستگاه» را انتخاب کنید؛ بستهٔ فارسی/ژاپنی باید در موتور گفتار همان دستگاه موجود باشد. محلی یا شبکه‌ای‌بودن موتور گفتار سیستم مستقل است.

اگر Groq تنظیم نشده باشد و Whisper محلی در نخستین بررسی آماده باشد، تشخیص گفتار محلی به‌صورت پیش‌فرض انتخاب می‌شود. انتخاب دستی شما حفظ می‌شود. نصب ناقص، موتور را آماده نشان نمی‌دهد و شکست آن باعث ارسال خودکار صدا به سرویس ابری نمی‌شود.

## نصب روی رایانهٔ دیگر

از ریشهٔ پروژه:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-LocalVoice.ps1
```

Python 3.10 یا جدیدتر لازم است. می‌توان مسیر مفسر را داد:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-LocalVoice.ps1 -PythonPath 'C:\Python312\python.exe' -Model small
```

راه‌انداز محیط جدا را در `.local/whisper/venv` ایجاد، نسخهٔ مشخص faster-whisper را نصب و فقط مدل انتخاب‌شده را دانلود می‌کند. دانلود اولیه اینترنت می‌خواهد. اگر فایل کامل نشده باشد، اجرای دوباره همان فرمان دانلود را ادامه می‌دهد. برای مشکل دسترسی به PyPI، می‌توانید آدرس مخزن بسته را مشخص کنید؛ در این محیط نصب با آینهٔ Tsinghua انجام شد:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-LocalVoice.ps1 -PackageIndex https://pypi.tuna.tsinghua.edu.cn/simple
```

پس از نصب، سرور CatTalk را دوباره اجرا و «بررسی دوباره» را بزنید. بررسی آمادگی برای کاهش هزینهٔ اجرا تا ۱۰ ثانیه کش می‌شود؛ اگر بلافاصله بعد از نصب هنوز آماده نبود، کمی بعد دوباره بررسی کنید.

## مدل و تنظیمات

```dotenv
LOCAL_WHISPER_MODEL=small
LOCAL_WHISPER_QUALITY_MODEL=small
LOCAL_WHISPER_DEVICE=cpu
LOCAL_WHISPER_COMPUTE=int8
LOCAL_WHISPER_THREADS=4
LOCAL_WHISPER_PYTHON=
```

خالی‌بودن مسیر Python یعنی استفاده از محیط جداگانهٔ پروژه. نام مدل به پوشهٔ `.local/whisper/models/<name>` اشاره می‌کند؛ مسیر مطلق یک مدل CTranslate2 محلی نیز قابل تنظیم است. نام/URL مدل از درخواست کاربر پذیرفته نمی‌شود. این تنظیم‌ها فقط برای سرور هستند.

راه‌انداز مدل‌های چندزبانهٔ `tiny`، `base`، `small`، `medium` و `large-v3` را می‌پذیرد. از نسخه‌های `.en` استفاده نمی‌شود. فایل وزن `small` دانلودشده حدود ۴۸۴ مگابایت است؛ مجموع با tokenizer و کتابخانه‌های Python بیشتر است. مدل کوچک‌تر می‌تواند روی دقت، لهجه و نام‌ها اثر منفی بگذارد. مدل بزرگ‌تر نیز به حافظه و زمان بیشتری نیاز دارد؛ برتری سرعت/دقت روی دستگاه شما باید سنجیده شود.

«محلی سریع‌تر» جستجوی beam=1 و «محلی با جستجوی بیشتر» beam=5 دارد. با تنظیم پیش‌فرض، هر دو از همان مدل small استفاده می‌کنند؛ برچسب دوم تضمین دقت بیشتر نیست. برای مدل مستقلِ حالت دوم ابتدا آن مدل را با `-Model` نصب و `LOCAL_WHISPER_QUALITY_MODEL` را تنظیم کنید. مدلِ نصب‌نشده برای آن حالت غیرفعال است.

پیش‌فرض CPU با int8 و چهار رشته است. CUDA فقط در صورت تنظیم صریح و نصب وابستگی‌های سازگار NVIDIA قابل استفاده است؛ در این محیط روی GPU آزمایش نشده است. تغییر تعداد رشته‌ها به‌تنهایی تضمین سریع‌ترشدن نیست.

## اجرا و کاهش هزینه

- یک فرایند خصوصی Python از طریق stdin/stdout به سرور Node وصل است؛ پورت عمومی یا endpoint مدلِ اضافی ندارد.
- هر بار فقط یک مدل در حافظه نگه داشته می‌شود و درخواست بعدی از مدل گرم استفاده می‌کند. شروع سرد شامل بارگذاری وزن است.
- صف سرور حداکثر سه درخواست، شامل درخواست فعال، دارد و به‌ترتیب پردازش می‌شود. صدا خودکار دوباره امتحان نمی‌شود.
- لغو پردازشِ فعال، فرایند مدل را متوقف می‌کند تا مصرف CPU ادامه پیدا نکند؛ درخواست بعدی مدل را دوباره بارگذاری می‌کند. بستن سرور نیز فرایند را پاک‌سازی می‌کند.
- راهنمای نام‌ها، همان حداکثر هشت نام و ۱۶۰ بایتِ انتخاب‌شده از واژه‌نامه است؛ فقط در صورت فعال‌سازی کاربر ارسال می‌شود.
- ورودی در حافظه به mono/16kHz تبدیل می‌شود. PyAV همراه کتابخانه‌هاست و نصب جداگانهٔ FFmpeg لازم نیست. فایل موقت دیگری روی دیسک سرور نوشته نمی‌شود.

محدودیت حجم شش مگابایت، زمان ۱۲۵ ثانیه و متن دو هزار نویسه است. متن طولانی خودکار بریده نمی‌شود. VAD محافظه‌کارانهٔ faster-whisper برای سکوت طولانی استفاده می‌شود؛ کل متن خروجی یک نوبت، یک‌جا به ترجمه می‌رود. این کار ترجمهٔ تکه‌های ناقص حین صحبت نیست.

## آفلاین و داده

موتور با `local_files_only=True`، `HF_HUB_OFFLINE=1` و telemetry خاموش اجرا می‌شود. دریافت مدل فقط در اسکریپت نصب انجام می‌شود. فرایند Python کلیدهای سرویس ابری یا توکن خصوصی سرور را دریافت نمی‌کند. صوت، متن و خطای خام Python در لاگ ثبت نمی‌شوند. صدا داخل همین رایانه پردازش می‌شود و برای این مرحله هزینهٔ API ندارد؛ برق، سخت‌افزار و میزبانی احتمالی هزینهٔ خودتان است.

اجرا روی رایانهٔ سرور است، نه داخل گوشی. گوشی باید به سرور CatTalk دسترسی داشته باشد؛ در LAN باید نشانی و توکن اتصال خصوصیِ سرور تنظیم شوند. انتخاب ترجمهٔ متن ابری یا صدای Gemini همچنان مرحلهٔ مربوط را به سرویس ابری می‌فرستد. برای مسیر بدون هزینهٔ API، Whisper محلی + موتور متن محلی + صدای دستگاهِ آماده را انتخاب کنید. OCR تصویر همچنان مستقل و مبتنی بر Gemini است.

## بررسی‌های انجام‌شده

- هشت آزمون Node برای آمادگی مدل، جداسازی اعتبارنامه، فرایند پایدار، دو جهت زبان، سقف صف، لغو واقعی فرایند، مهلت اجرا، خطای پروتکل و احراز هویت gateway؛ این آزمون‌ها worker پروتکلی آزمایشی دارند.
- چهار آزمون Python با WAV مصنوعی برای decode واقعی mono/stereo، سکوت، خرابی، سقف مدت و تنظیم مدل آفلاین؛ مدل زبانی در این واحدها mock است.
- آزمون مرورگر `tests/local-voice-ui.cjs` برای نبود مدل، تازه‌شدن آمادگی، فایل فارسی/ژاپنی، میکروفون جلسه و نبود fallback ابری؛ پاسخ HTTP در این آزمون fixture است.
- اجرای **مدل واقعی small** در `tests/local_whisper_smoke.py` با اتصال شبکهٔ مسدودشده موفق بود. ورودی آن صدای انگلیسی سیستم است که عبارت‌های آوانویسی‌شدهٔ فارسی/ژاپنی را می‌خواند؛ این ورودی تلفظ بومی ندارد، خطای تشخیص داشت و معیار دقت زبان نیست. گزارش در `artifacts/local-whisper-smoke.json` ثبت می‌شود.
- endpoint واقعی `/api/transcribe` با مدل small و بدون کلید نیز متن برگرداند. کیفیت روی گفتار طبیعی، لهجه، محیط شلوغ و گوشی فیزیکی هنوز سنجیده نشده است. برای متن مهم، بازبینی را فعال کنید.
