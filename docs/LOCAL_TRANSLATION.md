# ترجمهٔ کاملاً رایگان در اجرای محلی

سه گزینه به فهرست هوش مصنوعی اضافه شده‌اند: **TranslateGemma محلی، Qwen محلی و LibreTranslate محلی**. برچسب داخل اپ دقیقاً «کاملاً رایگان در اجرای محلی» است: برای ترجمهٔ متن روی سخت‌افزار خودتان، کلید API، پرداخت هر ترجمه یا سهمیهٔ تجاری ارائه‌دهنده ندارند. دانلود اولیه، اینترنت، برق، سخت‌افزار و میزبانی احتمالی هزینهٔ خودتان است. اپ همچنان برای جلوگیری از درخواست زیاد، محدودیت فنی سرعت درخواست دارد.

این‌ها سرویس عمومی رایگان و نامحدودِ میزبانی‌شده نیستند. Gemini، Groq و OpenRouter Free با عنوان «سهمیهٔ رایگان محدود» مشخص شده‌اند. OpenAI با عنوان API پولی مشخص است.

## گزینه‌ها و منابع رسمی

| گزینه | کاربرد و محدودیت | مجوز / منبع |
|---|---|---|
| TranslateGemma 4B | مدل تخصصی ترجمه، پشتیبانی فارسی و ژاپنی؛ اجرای محلی با Ollama، دانلود مدل حدود ۳٫۳ گیگابایت بر اساس فهرست فعلی؛ در اپ فقط حفظ لحن متن، بدون زمینهٔ سفارشی | [مدل و زبان‌ها](https://ollama.com/library/translategemma)، [مدل اصلی Google](https://huggingface.co/google/translategemma-4b-it)، [شرایط Gemma](https://ai.google.dev/gemma/terms/) |
| Qwen3 4B | مدل عمومی چندزبانه با قابلیت ترجمه؛ پشتیبانی دستور لحن و زمینه؛ حالت thinking خاموش است و فقط خروجی متن نمایش داده می‌شود | [مدل Ollama](https://ollama.com/library/qwen3)، [مدل اصلی Qwen / Apache 2.0](https://huggingface.co/Qwen/Qwen3-4B) |
| LibreTranslate / Argos | موتور تخصصی ترجمهٔ خودمیزبان؛ نصب fa، ja و en لازم است. ممکن است فارسی ↔ ژاپنی از انگلیسی به‌عنوان واسطه عبور کند؛ تنظیم زمینه و لحن ندارد و پاسخ را یک‌جا برمی‌گرداند | [کد و AGPL-3.0](https://github.com/LibreTranslate/LibreTranslate)، [زبان‌ها و مسیر واسطه](https://docs.libretranslate.com/guides/supported_languages/)، [نصب](https://docs.libretranslate.com/guides/installation/) |

منابع در ۲۶ اکتبر ۲۰۲۶ بررسی شدند. رایگان‌بودن به معنی بی‌خطابودن ترجمه یا نبود شرایط مجوز نیست. مدل‌های کوچک و ترجمهٔ واسطه‌ای باید با نمونه‌های واقعی فارسی–ژاپنی ارزیابی شوند؛ کیفیت و سرعت این مدل‌ها روی این رایانه هنوز سنجیده نشده است.

## راه‌اندازی

در بررسی فعلی، Ollama نصب نیست و Docker Desktop هم موتور فعال ندارد. اتصال‌ها، تشخیص آماده‌بودن موتور و لانچر آماده‌اند؛ مدل‌ها هنوز دانلود نشده‌اند. اپ موتور نصب‌نشده را آماده نشان نمی‌دهد.

راه اول، نصب [Ollama](https://ollama.com/download) و اجرای برنامهٔ آن است. سپس یکی از فرمان‌های زیر را از ریشهٔ پروژه اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-LocalTranslation.ps1 -Engine TranslateGemma
powershell -ExecutionPolicy Bypass -File .\Start-LocalTranslation.ps1 -Engine Qwen
```

لانچر مدل انتخاب‌شده را دانلود می‌کند؛ هر فرمان فقط همان مدل را می‌گیرد. برای اجرای مستقیم می‌توانید از `ollama pull translategemma:4b` یا `ollama pull qwen3:4b` استفاده کنید. مدل‌های بزرگ‌تر را فقط پس از بررسی حافظه و توان دستگاه انتخاب کنید؛ نسخهٔ بزرگ‌تر به‌صورت خودکار دانلود نمی‌شود.

راه دوم، روشن‌کردن موتور Linux در Docker Desktop و استفاده از همان لانچر است. در نبود Ollama نصب‌شده، لانچر از `compose.local.yml` استفاده می‌کند. کانتینرها فقط روی loopback منتشر می‌شوند. اجرای Docker در این فایل به CPU متکی است؛ تنظیم GPU اختیاری در این مرحله اضافه نشده است.

برای LibreTranslate:

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-LocalTranslation.ps1 -Engine LibreTranslate
```

دانلود نخستین زبان‌ها زمان می‌برد. برای مشاهدهٔ پیشرفت، `docker compose -f compose.local.yml logs libretranslate` را اجرا کنید. تصاویر کانتینر از منابع رسمی‌اند و نسخهٔ `latest` هنگام راه‌اندازی دریافت می‌شود؛ برای انتشار قابل تکرار، پس از آزمون نسخه/هش تصویر را قفل کنید. Docker Desktop شرایط مجوز خودش را دارد؛ خود موتورهای ترجمه هزینهٔ API ندارند.

سپس `Start-Translation.ps1` را اجرا کنید، در اپ موتور محلی را انتخاب کنید و «بررسی دوباره» را بزنید. اتصال پیش‌فرض:

```dotenv
OLLAMA_URL=http://127.0.0.1:11434
LIBRETRANSLATE_URL=http://127.0.0.1:5000
```

این متغیرها در `.env` آماده‌اند. فقط نشانی loopback پذیرفته می‌شود تا بخش «محلی رایگان» به endpoint ابری تبدیل نشود. در موبایل، آدرس سرور CatTalk روی رایانه/سرور خودتان را تنظیم کنید؛ موتور محلی از دید همان سرور اجرا می‌شود، نه روی گوشی.

پیش‌فرض هر سه حالت کیفیت/سرعت برای هر مدل محلی یک مدل نصب‌شده است. شناسه‌های مدل در متغیرهای `TRANSLATEGEMMA_TRANSLATION_*` و `QWENLOCAL_TRANSLATION_*` قابل تغییرند. اپ وجود مدل انتخابی را بررسی می‌کند؛ مدل‌های ابری با نام cloud در این بخش پذیرفته نمی‌شوند. تنظیم لحن/زمینه هنگام انتخاب TranslateGemma یا LibreTranslate پاک و غیرفعال می‌شود تا گزینه‌ای بدون اثر نشان داده نشود.

## محدودهٔ رایگان‌بودن صوت

برچسب این سه گزینه مربوط به **مرحلهٔ ترجمهٔ متن** است و برای متن استخراج‌شده از ویس هم قابل استفاده‌اند. تشخیص گفتار فعلی همچنان Groq یا Gemini است و کلید/سهمیه می‌خواهد. پخش با صدای نصب‌شدهٔ دستگاه کلید لازم ندارد؛ پخش Gemini به سهمیهٔ صوتی آن وابسته است. با انتخاب موتور متن محلی، کل مسیر صوتی آفلاین و نامحدود نمی‌شود.

در صورت خطا، اپ خودکار به سرویس ابری یا پولی سوییچ نمی‌کند. آزمون‌های adapter و رابط از پاسخ‌های آزمایشی استفاده می‌کنند؛ تا نصب مدل واقعی، ادعای دقت یا سرعت واقعی مطرح نیست.
